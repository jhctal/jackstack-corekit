# @jackstack/corekit

**React components, built from the core.**

A modular and customizable component library for building elegant, accessible UIs with React and TailwindCSS.

---

## ✨ Features

- 🧩 Modular, tree-shakeable components
- 🎨 TailwindCSS-based design system
- ⚙️ Built-in support for `react-hook-form`
- 🧠 Smart defaults, flexible overrides
- 🧪 TypeScript included

---

## 📦 Installation

```bash
npm install @jackstack/corekit
# or
yarn add @jackstack/corekit
```
